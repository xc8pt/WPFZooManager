Назначение программы
Приложение предназначено для управления данными о зоопарках и животных в базе данных.
Позволяет просматривать список зоопарков, связанных с ними животных, а также полный список животных. 
Реализует базовые операции управления данными: добавление, удаление и обновление информации о зоопарках и животных.​

Реализованные функции:

1. Просмотр списка зоопарков из базы данных
2. Просмотр животных, связанных с выбранным зоопарком
3. Просмотр полного списка всех животных
4. Добавление, обновление и удаление зоопарков
5. Добавление, обновление и удаление животных
6. Связывание животных с выбранным зоопарком и удаление связи
7. Сообщение об ошибках при возникновении исключений

Как запустить проект?

1. Клонируйте репозиторий с исходными файлами.
2. Откройте проект в Visual Studio.
3. Проверьте строку подключения к базе данных в файле настроек (app.config или Settings.settings). Убедитесь, что база данных доступна.
5. Постройте и запустите проект (кнопка Start или F5).
6. В открывшемся окне можно работать с зоопарками и животными (редактирование, добавление, удаление и связывание).​
(Если потребуется, установите необходимые NuGet-пакеты для работы с SQL Server (например, System.Data.SqlClient)).
